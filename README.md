# E-Commerce Sales Analysis using SQL

## Project Overview
This project analyzes a real e-commerce sales dataset using SQL queries to extract business insights.

## Dataset
- Source: Kaggle (E-Commerce Sales Dataset by The Devastator)
- Rows: 9,272
- Columns: SKU Code, Design No., Stock, Category, Size, Color

## Key Business Questions Answered
1. Total stock by color
2. Total stock by size
3. Number of SKUs per category
4. Top 5 categories by stock
5. Stock analysis for BLOUSE category
6. Categories with stock greater than 500
7. Top 3 least stocked colors
8. RED color L size SKU count
9. SKU code pattern search
10. Products with stock greater than 10

## Tools Used
- SQL (SQLite)
- DB Browser for SQLite

## Key Insights
- BLOUSE category has the highest number of SKUs (234)
- AQUA GREEN color has the lowest stock (5 units)
- Dataset contains NULL values indicating real-world data quality issues
- 8,027 out of 9,272 products have stock greater than 10
